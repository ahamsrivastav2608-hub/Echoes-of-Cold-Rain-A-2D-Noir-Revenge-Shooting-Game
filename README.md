# Echoes-of-Cold-Rain-A-2D-Noir-Revenge-Shooting-Game
Echoes of Cold Rain is a story-driven 2D top-down action shooting game centered on grief, vengeance, and the haunting search for closure.  You play as Daniel Ward, an ex-homicide detective whose wife Clara and 7-year-old daughter Lily were executed in a calculated syndicate hit.
